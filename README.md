# Leveraging bioacoustics in a community ecology framework for quantifying West Nile virus risk and mitigation planning

R code for power analyses informing WNV study design for project submitted to BBSRC responsive mode.

## Contents
  - **StudyDesignPowerAnalysisAdults.rmd**: study design for adult abundance.
  - **StudyDesignPowerAnalysisLarvae.rmd**: study design for larval presence. 

## Getting Started
To run the code:  
1. Open either R Markdown file.  
2. Ensure all required libraries are installed.
3. Run each code chunk.
